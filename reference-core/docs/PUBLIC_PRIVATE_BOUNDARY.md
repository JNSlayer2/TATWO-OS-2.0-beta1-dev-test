# Public / Private Boundary

## Allowed in this repository

Portable documentation, protocol schemas, pure validation functions, dry-run previews, synthetic examples, hermetic tests, and security policy.

## Never copy from a private installation

- `.git`, hidden tool configuration, editor state, caches, build products, logs, reports, receipts, screenshots, attachments, databases, or session transcripts.
- Environment files, tokens, keys, cookies, browser profiles, provider account state, signing assets, device enrollment, network endpoints, or machine identifiers.
- Absolute home or volume paths, usernames, account addresses, project names that identify clients, or real working-directory data.
- Launch agents, installers, auto-updaters, device-control scripts, deployment credentials, remote-control configuration, or trading authority.
- Real project fixtures or model outputs, even when they appear harmless.

## Selection rule

Re-author the smallest provider-neutral behavior from the architectural idea. Do not copy a private tree and then attempt to redact it. If provenance or licensing is unclear, exclude the file.
