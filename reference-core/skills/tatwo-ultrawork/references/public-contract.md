# Public Collaboration Contract

A public run records: outcome, success evidence, non-goals, constraints, protected surfaces, known context, unknowns, room briefs, validation commands, rollback, and final state.

The contract is descriptive unless an external runtime explicitly binds and enforces it. Text in a prompt is not a security boundary. A host adapter must authenticate the user, constrain paths and processes, apply resource limits, protect secrets, and log authority-changing actions.
