# TATWO OS 2.0 Public Edition

A portable, fail-closed reference core for multi-engine AI collaboration. It is a clean-room public package, not a mirror of a private workstation or a source dump of the full desktop application.

It includes the thin OS constitution, a provider-neutral sidecar protocol, room-brief and report-merging primitives, a dry-run CLI, a portable `tatwo-ultrawork` skill, tests, and a public-safety scanner. It excludes credentials, sessions, device control, private receipts, real project fixtures, local paths, private Git history, automatic installation, and background services.

Run `npm run check` with Node.js 20 or later. No package installation is required.
